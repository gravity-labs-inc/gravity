## Install

1. Download [Gravity for Mac (Apple Silicon)](https://github.com/gravity-labs-inc/gravity/releases/latest/download/gravity-macos-arm64.dmg). Requires macOS 13 or later.
2. Open the downloaded `.dmg` and drag **Gravity** into **Applications**.
3. Open Gravity from Applications. The daemon starts automatically.
4. If macOS says it can't verify Gravity, open **System Settings → Privacy & Security** and click **Open Anyway**.

You need at least one agent CLI installed and signed in, such as [Claude Code](https://docs.anthropic.com/en/docs/claude-code) or [Codex](https://github.com/openai/codex).

All builds are on the [releases page](https://github.com/gravity-labs-inc/gravity/releases).
